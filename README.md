# ankimodel

#### 介绍

anki模板-内含基础功能+笔记标记系统+图片遮盖系统 【挖空转换+图片系统+标记系统+大纲伸缩+卡片链接+卡内搜索+弹窗管理+引用处理】

#### 模板类型

- 00-00-划线挖空（单卡多空）：下划线自动转化为填空（一张卡片多个填空）。
- 00-01-标准挖空（多卡多空）：anki原始填空模板改造而来，除将{{文本}}转换为填空（多卡多空）之外，也会将下划线自动转化为填空（单卡多空）。
- 00-02-选择题：自动判断单选、多选、是非题型，自动判断对错、统计用时及正确率（可重置）。windows端在选定选项后会自动翻转，移动端仍需手工点击答案才可翻转至卡片背面。
- 00-03-Basic：anki原始Basic模板改造而来
- 00-04-图片遮盖：anki原始图片遮盖模板改造而来
- 01-01-标准挖空【含云深制卡解密】：云深制卡笔记模板改造而来，含云深卡片解密内容
- 01-02-选择题【含云深制卡解密】：云深制卡选择题笔记模板改造而来，含云深卡片解密内容

- 说明：无论是哪一种类型的模板，均包含基础功能+笔记标记系统+图片遮盖系统所有功能

#### 安装教程

- 方法1.  复制front内容至anki模板正面，复制back内容至anki模板反面，复制css内容至anki模板样式（需要先选定相应的基础模板，并自行增加笔记标记系统及图片遮盖系统所需字段）
- 方法2.  下载.apkg文件后直接导入至anki


#### 基础功能

- 说明：基础功能很大程度上借鉴的是云深制卡笔记模板的功能样式，是在云深制卡笔记模板的基础上进一步优化而来。右列菜单栏对选择题同样适用，只是选择题是横向摆放。
- 主题切换：内置6个主题样式，可通过点击右列菜单栏内主题菜单进行切换（样式色彩搭配不满意的可以自行更改模板中的样式部分）
- 页眉页脚：左侧显示用时，右侧显示倒计时【自行在正反面模板中找到`var examDate = new Date("2026-08-29");`，将日期改为自己需要的日期）】，中间的显示不同的模板略有不同，可自行更改（只需要将字段替换为自己需要的字段）。
   - 00-00-划线挖空（单卡多空）：`<div class="linkRender" id="source-display">➵{{Deck}} </div>`，即显示“➵牌组”
   - 00-01-标准挖空（多卡多空）：`<div class="linkRender" id="source-display"> {{Deck}}➵{{标题}} </div>`，即显示“牌组➵标题”
   - 00-02-选择题：` <div class="linkRender" id="source-display">{{来源}}➵{{考点}}</div>`，即显示“来源➵标题”
   - 00-03-Basic：`<div class="linkRender" id="source-display">➵{{Deck}}</div>`，即显示“➵牌组”
   - 00-04-图片遮盖：`<div class="linkRender" id="source-display"> {{Deck}}➵{{标题}} </div>`，即显示“牌组➵标题”
- 挖空转换：自动将下划线转换为填空，并可通过点击右列菜单栏内`cloze`按钮实现一键切换所有填空显示/隐藏状态，点击`Ncloze`按钮则切换下一个填空显示/隐藏状态
- 大纲伸缩：自动将`H1-H6`转换为`<details><summary>`语句，实现正确的嵌套及大纲伸缩。也可适配特定的云深制卡`children`结构。点击右列菜单栏内`展收`按钮可以一键展开/收缩所有节点；点击右列菜单栏内`定位`按钮则会自动收起所有节点，然后展开当前填空所在节点并自动跳转屏幕到该处【仅适用于00-01-标准挖空（多卡多空）模板】；右列菜单栏内`+标题`按钮需搭配笔记标记系统使用，在添加笔记类型的标记后编辑笔记时，若添加了`H1-H6`的内嵌标记，点击`+标题`按钮可直接将笔记编辑器中的`H1-H6`转换为可伸缩的节点。
- 卡片链接：实现在一张卡片中可以点击查看另一张卡片内容。电脑端安装`Anki Note Linker`插件可直接使用，移动端需要在模板中添加一部分代码并给字段加上`class="linkRender"`才可点击并跳转至卡片过滤界面自动完成过滤，需要用户自己再点击进入该卡片，具体的使用方法请参考`https://ankiweb.net/shared/info/1077002392`。本项目所有卡片模板均已适配该插件，无需用户再另外修改代码。
- 卡内搜索：点击右列菜单栏内`🔍`按钮或者点击页眉区域均会弹出搜索框，即可实现在当前卡片页面内搜索输入的文本（自动展开、高亮显示并定位），也可直接跳转至外部链接进行搜索，内置6个外部链接（粉笔公务员/事业单位、学习强国、会计准则委员会、国家法律法规数据库、DeepSeek），有些跳转后需要先登录。
- 弹窗管理：既包含对4个特定字段（拓展、资料、笔记、归纳）的弹窗管理（字段有内容时会显示在菜单栏中，点击即可打开查看该字段内容，字段无内容时则无相应菜单按钮），也包含对标记标记系统及图片遮盖系统相关菜单弹窗的管理。所有弹窗均可缩放（拖动弹窗右下角缩放图标）、移动（点击弹窗标题栏并进行拖动）、点击外部关闭、层叠置顶（活动窗口自动提到最前面）。
- 引用处理：在用calibre将epub书籍中的内容直接复制黏贴到anki时，会自动处理书籍中的引用结构`<a href="javascript:void(0)"><sup>(22)</sup></a>`、`<a href="javascript:void(0)">(22)</a>`。适配word批注`#_msocom_2`、`#_msoanchor_2`结构，word脚注`#_ftn1`、`#_ftnref1`结构，word尾注`#_edn1`、`#_ednref1`结构。
